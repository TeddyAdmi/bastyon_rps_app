# Bastyon RPS Mini-App (Камень Ножницы Бумага)

Готовое мини-приложение для платформы **Bastyon / Pocketnet** ([bastyon.com/devapplications](https://bastyon.com/devapplications)).

## 🌟 Возможности
- **Подключение в 1 клик:** Автоматическое определение ника, аватара и баланса пользователя через Bastyon SDK.
- **Комната 1 (Бесплатная):** Игра против бота для тренировки и ознакомления.
- **Комната 2 (PvP на 1 PKOIN):**
  - Ставка 1 PKOIN переводится на игровой кошелек.
  - Таймер на 24 часа.
  - Отображение актива игроков в сети.
  - Победитель удваивает ставку и получает **1.9 PKOIN** (за вычетом 5% комиссии сервиса).

## 🚀 Пошаговый деплой (Vercel / GitHub)

### Способ 1: Vercel (Самый быстрый)
1. Скачайте файлы проекта.
2. Установите [Vercel CLI](https://vercel.com/download) или зайдите на [vercel.com](https://vercel.com).
3. Создайте новый проект, выберите папку с исходным кодом и нажмите **Deploy**.
4. Скопируйте итоговый URL (например, `https://bastyon-rps.vercel.app`).

### Способ 2: GitHub Pages
1. Создайте публичный репозиторий на GitHub.
2. Загрузите файлы проекта (`index.html`, `app.js`, `style.css`, `b_manifest.json`).
3. Перейдите в **Settings** -> **Pages** -> выберите ветку `main` (`/root`) и сохраните.
4. Скопируйте ссылку на опубликованную страницу.

## 📱 Регистрация в Bastyon
1. Перейдите на [https://bastyon.com/devapplications](https://bastyon.com/devapplications).
2. Нажмите **Добавить новое приложение**.
3. Вставьте ссылку с Vercel / GitHub Pages.
4. Укажите адрес вашего кошелька для приема ставок и комиссии в `app.js` (`APP_WALLET_ADDRESS`).
